# Agentic-Z 2.0.0

Major release. Agentic-Z grows from a set of helpers into a full mod team: 30 agents (up from 14) and 40 DayZ skills (up from 25), edit hooks, a token-saving layer, a side panel and answer tests. One breaking change is listed under "What's gone".

## What's new

### A mod team with an orchestrator, leads and gates

- **`dayz-orchestrator`** runs as your main session and plans the whole mod.
- **`dayz-router`** (Haiku) picks the handler when the free keyword rules in `/dayz-route` are not sure.
- **`dayz-mod-architect`** writes the plan, and **`dayz-lead`** runs one team (script, config, art, UI, server, release) and its gates.
- **`dayz-build-engineer`**, **`dayz-build-checker`** and **`dayz-ingame-tester`** build the mod and run the build and in game gates.
- **`dayz-docs-writer`** keeps the mod's README, changelog and classname list current.

### Eight new specialists, each with a knowledge pack

- `dayz-persistence-specialist`: data that survives a restart, save versions, base building.
- `dayz-ai-specialist`: infected, animals and AI behaviour.
- `dayz-animation-specialist`: doors, user animations and model sources.
- `dayz-physics-specialist`: geometry, mass and the model audit.
- `dayz-vehicle-specialist`: cars, boats, damage zones and parts.
- `dayz-weapon-specialist`: weapons, magazines and attachments.
- `dayz-wearables-specialist`: clothing, vests, protection and camo.
- `dayz-audio-fx-specialist`: sound sets, effects and memory point sounds.

The packs live under `.claude/skills/_shared/`, next to new packs for Enforce Script (language and core API), UI widgets, textures and rvmats, and models and LODs. Every fact in them was checked against vanilla source.

### New skills

| Skill | What it does |

| `/dayz-recipe` | Pre-fills the architect plan for a new weapon, vest or craftable. |
| `/dayz-lint` | Finds errors that would stop a mod loading, before it is packed. |

| `/dayz-balance` | Compares item stats with similar vanilla items and flags outliers. |
| `/dayz-conflict-check` | Reports prefix, path and class name collisions with CF, COT and Expansion. |
| `/dayz-upgrade-guard` | Flags mod classes whose vanilla parents changed in a DayZ update. |
| `/dayz-ask` | Answers a question about vanilla with checked `path:line` citations. |
| `/dayz-layout-preview` | Renders a `.layout` to PNG previews at several screen sizes. |
| `/dayz-release-pack` | Writes the Workshop text, a changelog entry, the classname list and install notes. |

| `/dayz-route` | Picks the skill, agent or team for a request with free keyword rules. |

`/dayz-init` gained an optional spec step that writes `workspace/<ModName>/spec.md`.

### Hooks

- **Edit check** syntax-checks `config.cpp` and `.layout` files after every edit.
- **Scope guard** keeps edits inside the mod set with `/dayz-scope-mod`.
- **Paste-in router** sends pasted crash logs to triage, types.xml chunks to a checked merge, and Figma or GitHub links to their workflow.

### Token-saving layer

Script-only gates, log triage, the cheap router, the status line and a `.bat` wrapper in `scripts/` for every runnable skill mean most routine steps cost no model tokens. Skill descriptions are shorter, so less loads per session. See `docs/token-saving.md`.

### Side panel (`agentic-z-panel` 0.3.0)

A new second plugin in the marketplace. It shows DayZ state beside the chat and has one-click buttons for mount, build, checks, deploy, launch, stop, Workbench, Object Builder, test logs, the health page and the release pack, plus a field that asks `/dayz-ask`. Install with `/plugin install agentic-z-panel@dayz-n-chill`.

### Answer tests and CI

- Answer tests (evals) check that agents give correct DayZ answers. See `docs/evals.md`.
- GitHub Actions runs the test suite, hooks tests included, on pull requests and on `develop` and `main`.

### Security

Every agent has an explicit tool allowlist, run-only gates get no Edit or Write, and no agent has network tools. The security model is documented in the README.

## What's gone (breaking)

- **Wiki search removed.** The wiki crawler, `/dayz-search-wiki-index` and the `search_dayz_wiki` MCP tool are gone. The `dayz-rag` server now searches vanilla DayZ source only.

## Fixes

Repeated grading passes across every agent, skill, pack and hook corrected vanilla facts, handoffs and edge cases. Highlights:

- Skills find the DayZ project from `DAYZ_PROJECT` or the current folder first, so a second project on the same machine no longer picks up the wrong workspace.
- `/dayz-build-pbo` packs `.styles` UI files.
- `/dayz-launch-test --server-only` keeps server-only mods off the client.
- `/dayz-conflict-check --ingame` accepts linked `@mods`.
- `/dayz-import-mod` tells the truth about removing a git clone.
- `/dayz-init` never writes `spec.md` into a linked import on a re-run.
- `/sync-skills` links `_shared` and guards against one clone taking over another.
- The brand is spelled DayZ n' Chill everywhere.

## Upgrading from 1.6.0

`/plugin update agentic-z` fetches the new version. Restart Claude Code afterwards so the new agents, skills and hooks load. To add the panel, run `/plugin install agentic-z-panel@dayz-n-chill`.

With a clone of the repo, `/agentic-z-update` shows the diff and merges the template paths for you.

## Verification

1. Start a fresh Claude Code session.
2. Ask for "a new rifle mod". `/dayz-route` should print one JSON decision that names the weapon work.
3. Edit a `config.cpp` with a missing semicolon. The edit check hook should report it.
