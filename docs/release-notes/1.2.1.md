# Agentic-Z 1.2.1

Patch release on top of 1.2.0. No new features, no behavior changes; cleanup only.

## What changed

- **Plugin manifest correction.** Both `.claude-plugin/marketplace.json` and `.claude-plugin/plugin.json` had stale `version: "1.0.1"` and the plugin's `skills` array was missing `dayz-p3d-audit`, `dayz-p3d-debin`, and `dayz-particles`. Description count was off by one. Users installing via `/plugin install agentic-z@dayz-n-chill` now see all 23 skills with the correct version.
- **Removed internal process artifacts** (`docs/superpowers/`). Brainstorm spec and implementation plan for the auto-update v2 work served their purpose during build and live in git history; no need for them in the visible repo.

## Search index

Same 52,048 source chunks + 434 wiki chunks as 1.2.0, repackaged as `dayz-search-index-1.2.1.tar.gz` so the SessionStart hook resolves the latest release with a matching asset. Users with installed `1.2.0` will be nudged to re-download; the contents are identical, so re-downloading is optional unless you want the version match.

## Upgrading from 1.2.0

`/agentic-z-update` will surface 3 file changes (plugin manifest + 2 deletions). Apply with `y`. No conflicts expected.

## Upgrading from pre-1.2.0

Same workaround as 1.2.0 — see [1.2.0 release notes](./1.2.0.md) for the `PYTHONIOENCODING=utf-8` one-liner.
