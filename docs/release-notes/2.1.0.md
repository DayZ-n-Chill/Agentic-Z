# Agentic-Z 2.1.0

Agents and skills now load once. No changes to what the agents, skills or hooks do.

## Changed

- **Agents and skills load once.** They moved from `.claude/agents/` and `.claude/skills/` to `agents/` and `skills/` at the repo root, and the plugin supplies them. Before this, working inside a clone with the plugin installed loaded every agent and skill twice. The four repo-only skills (`agentic-z-update`, `clean-repo`, `docs-sync`, `sync-skills`) stay in `.claude/skills/`.
- **`CLAUDE.md` moved to `.claude/CLAUDE.md`.** `AGENTS.md` and `GEMINI.md` stay at the root.
- **The repo's settings enable the plugin.** `.claude/settings.json` adds the `dayz-n-chill` marketplace and turns on `agentic-z@dayz-n-chill`, and the repo's `.mcp.json` no longer starts its own copy of the `dayz-rag` server.

## Added

- **Plugin icons.** Both plugins in the marketplace now have an icon.
- **Privacy section in the README.** It lists what is sent to Voyage AI and TypeSafe, and when.

## Removed

- **The wiki hero image.** It belongs to the wiki, and at 5.9 MiB it was over the plugin directory's file size limit.
