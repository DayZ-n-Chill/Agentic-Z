# Agentic-Z 2.2.0

The knowledge pack update. The DayZ knowledge packs are rewritten and expanded, 18 offline tools and an in-game test bridge are added, and every graded item is at A+.

## Added

- **Two knowledge packs.** `skills/_shared/ui/` covers menus, HUDs and `.layout` files. `skills/_shared/world/` covers underground areas and the 1.30 hazards, such as sandstorms and heat stroke.
- **Two skills.** `/dayz-animation-pipeline` runs the animation tools: `model.cfg` from a JSON description, SEAnim and RTM files, and rider poses. `/dayz-model-tools` inspects and fixes source (MLOD) `.p3d` models.
- **18 offline tools under `scripts/tools/`.** They include an Enforce Script checker, a 3D model viewer, a `.layout` previewer, vehicle and object checks, a PBO compare and a navmesh compare. None of them call a model. `docs/tools.md` lists them all.
- **The `dayz-testbridge` in-game test tool.** An agent can test a mod inside a running DayZ Diag session with nobody at the keyboard: spawn objects and items, teleport the player, drive a car while reading its speed and state, and cast rays. Its `exec` command, which runs any script, is built but turned off, because DayZ Diag 1.30 blocks it. See `skills/dayz-launch-test/references/test-bridge.md`.
- **`THIRD_PARTY_NOTICES.md`** lists the licenses of third-party code in the repo.
- **A thank-you to the DayZ community** at the end of `LICENSE`. The license terms did not change.

## Changed

- **The knowledge packs are rewritten and expanded.** Every pack under `skills/_shared/` is in house style, and every DayZ fact in them was checked against the current vanilla code.
- **Every graded item is at A+.** Independent reviewers regraded all 747 items: every agent, every skill and every shared file. Each defect they found was fixed and regraded. The grades are in `docs/grades/`.
- **The search index** covers about 77,600 chunks of vanilla DayZ source.

## Removed

- **The outside DayZ-MCP tool is no longer needed** for in-game tests. `dayz-testbridge` replaces it, and its DayZ engine facts were kept in the knowledge packs.

## Upgrading from 2.1.0

Run `/plugin update agentic-z`, then restart Claude Code so the new skills and the test bridge load. In a clone, `/agentic-z-update` shows the changes to merge.
