The repo root now ships as a usable Obsidian vault (`.obsidian/` checked in). Open the repo as a vault to navigate `CLAUDE.md` ↔ `.claude/agents/` ↔ `.claude/skills/` ↔ `docs/` via graph view + backlinks — the same files the agents read.

{/* truncate */}

## What's included

- `.obsidian/` workspace config checked in so graph view, hotkeys, and theme are sane on first open.
- Community plugin manifest — Obsidian prompts to install Dataview, Templater, Excalidraw, Outliner, and Git on first open. Accept to enable repo-managed defaults; skip if you prefer your own setup.
- Per-user auto-memory still lives at `~/.claude/projects/<repo>/memory/` (outside the repo).

## Why

The agent stack is a graph — agents reference shared conventions, skills reference shared agents, docs reference both. Reading it as a tree of folders loses that. Obsidian's backlinks panel shows you "where else is this skill mentioned" instantly, which is the same question the agents are answering programmatically.
